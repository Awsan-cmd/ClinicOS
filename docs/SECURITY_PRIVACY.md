# Security and Privacy
ClinicOS may handle sensitive health/personal data.

Controls: secure authentication, MFA readiness, sessions, RBAC, tenant isolation, validation, web security protections, rate limiting, secure uploads, encryption, secret management, audit logs, consent, data minimization, export/delete where legally applicable, backup encryption, security headers, dependency/secret scanning, vulnerability management.

AI: prompt-injection defenses, tool allowlists, per-action authorization, PII minimization, audited tool calls, approval for high-risk actions, untrusted model output.

Compliance requirements depend on jurisdiction and must be assessed before claiming compliance.

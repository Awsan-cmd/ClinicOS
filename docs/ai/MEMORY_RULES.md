# Memory Rules
1. Repository is durable project memory.
2. Never rely solely on conversation history.
3. Update memory after meaningful work.
4. CURRENT_STATE must reflect reality.
5. FEATURES must distinguish planned/in-progress/completed.
6. DECISIONS records important decisions; never silently rewrite them.
7. CHANGELOG records history.
8. PROJECT_MAP and ARCHITECTURE reflect actual implementation after changes.
9. Never mark unverified work complete.
10. Check GitHub when available.
11. Never store secrets.
12. Resolve contradictions by inspecting current code/tests/GitHub.
13. A new AI must be able to resume without the original conversation.

# QA and Release
Test layers: unit, integration, API/contract, database, E2E, security, performance, AI evaluation, regression.

Critical scenarios: tenant isolation, auth, permissions, appointment conflicts, timezones, billing, patient access, duplicate webhooks, provider failures, AI authorization, handoff, retries, file permissions.

Release checklist: requirements, tests, build, security, performance where relevant, migration review, docs/memory, diff review, commit, push/PR, post-deploy verification.

# UI/UX Specification
Goals: fast reception workflow, clinician clarity, simple staff UX, responsive/mobile-friendly, Arabic RTL and English LTR, accessibility, consistent design system.

Navigation: Dashboard, Patients, Appointments, Calendar, Clinical, Dental, Billing, CRM, Inbox, Automations, AI, Reports, Files, Staff, Settings.

Key screens: authentication, setup, dashboard, calendar, patient profile/timeline, clinical encounter, dental chart, treatment plan, invoice/payment, CRM pipeline, inbox, AI configuration, knowledge base, automation builder, reports, settings/security/audit.

Always design loading, empty, error, success, confirmation, unsaved-state, and permission states.
